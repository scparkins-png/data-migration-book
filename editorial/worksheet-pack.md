# Worksheet Pack — contents list

Decision (Stuart, 25 Oct 2026): **option 3, hybrid.** In the handbook, each *Your Turn* is a few short questions. The answer space — tables, boxes and lines — lives in a downloadable worksheet pack that accompanies the handbook and the Flow7 templates. This works the same way in print, PDF and ebook.

- **Numbering:** the worksheet number matches the exercise number (Exercise 2.1 → Worksheet 2.1).
- **Format:** a printable PDF, with an Excel tab for any worksheet that is a table.
- **Delivery:** to be decided with the templates (Drive folder first, then stuartparkins.com).
- **In the manuscript:** each worksheet is marked `{{worksheet: N | title}}`. The build renders this as a "→ Worksheet N" pointer. If a print edition ever wants write-in space, the same marker can render blank lines instead.

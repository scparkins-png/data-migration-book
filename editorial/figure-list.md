## Image standards

- Print: 300 dpi at the size it will appear; CMYK-safe colours; no text smaller than 7 pt once placed.
- Web/PDF download: the same files, compressed copies generated by the build.
- File names: the figure ID (`fig-c3-01.png`).
- Every figure has a caption and, where it shows data, a text restatement (the book already does this for Figures 3.1 and 6.1 — keep the pattern).
